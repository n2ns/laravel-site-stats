# Security policy

N2N Stats receives requests from the public internet and guards a dashboard and an API, so we take
security reports seriously.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/n2ns/laravel-site-stats/security/advisories/new)
with a description, the affected version and, if possible, steps to reproduce.

We will acknowledge the report within a week and keep you informed until it is fixed.

## Supported versions

Only the latest release receives security fixes.
